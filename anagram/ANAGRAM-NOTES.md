# Darkglass Anagram port — pilot notes (drive + fuzz)

M4 pre-work, done without hardware. The pilot pair is **Hex Chain Drive**
(1-in/1-out, worker + NAM file param — exercises the most machinery) and
**Hex Chain Fuzz** (1-in/1-out, pure DSP).

## What exists

- `anagram/hexchain-drive.lv2/`, `anagram/hexchain-fuzz.lv2/`: complete
  bundles minus the `.so` — `plugin.ttl` + `manifest.ttl` generated by
  `build-tools/gen_anagram.py` (a transform of the pi-Stomp TTLs, so knob
  definitions/scalePoints can never drift), `block-on/off.png` (200×200) by
  `build-tools/gen_anagram_assets.py` in the Hex Chain tile language.
- Source guards: `-DHEXCHAIN_ANAGRAM=ON` (root CMake option) appends an
  `enabled` port (`lv2:enabled` designation, default 1) and a `reset` port
  (`kx:Reset`, `pprops:trigger`) to both plugins and compiles DenormalGuard
  out (KosmOS forbids touching global CPU registers). Default build is
  byte-identical — the guards are pure preprocessor.
- Port order: drive's enabled/reset sit BEFORE the atom ports (indices 11/12,
  atoms 13/14) — mod-host, which KosmOS also runs, breaks when control ports
  follow atoms. TTLs renumbered to match the enum exactly.
- Compile gates: `anagram_check_default` + `anagram_check_anagram` object
  targets in build-tools build both TUs in both flag states.
- TTL shapes copied from Darkglass's own reference plugin
  (dark-plugins/dark-tremolo.lv2): `dg:abbreviation`, enabled/reset port
  shapes, `pg:MonoGroup` audio grouping.

## Audits (KosmOS REQUIREMENTS.md)

| Requirement | Status |
| --- | --- |
| 1-in/1-out mono | ✓ both plugins already are |
| Dual-mono determinism (identical input ⇒ identical output) | ✓ zero RNG/time hits across all drive + fuzz models (grep audit); state is input-driven only |
| kx:Reset resyncs state | ✓ implemented as full `prepare()` re-init on rising edge. **Provisional**: prepare() allocates; Reset only fires on host preset/bank/pairing events, but if device xruns appear, add allocation-free `reset()` to OverdriveBlock/OversamplingWrapper |
| Parameter smoothing | ✓ spot-check: models smooth internally (TS808 16 hits, Muff 13, ToneBender 2, FizzFactory 4). Per-port zipper listen on device |
| No global CPU register changes (FTZ) | ✓ DenormalGuard compiled out under the flag (fuzz never had one). Watch idle/decay CPU on device — aarch64 denormal cost without FZ is the reason the guard existed |
| Survive 0-sample runs | ✓ code-reviewed: bypass memcpy(0) is a no-op, chunk loops don't execute; confirm on device |
| No self-modification of params | ✓ neither plugin writes an input port |
| lv2:enabled ControlPort default 1 | ✓ |
| 0 dBFS = 3.119 Vrms reference | n/a until device gain-staging check |
